# Falcon K2 LiDAR Recorder

Benewake Falcon K2 LiDAR から UDP で点群を受信し、**前フレームとの差分（変化点）のみ**を PCD ファイルとして連続保存するデスクトップアプリケーションです。

---

## 機能

| 機能 | 詳細 |
|------|------|
| **UDP 受信** | 任意の IP アドレス・ポートを UI で設定可能 |
| **差分検出** | ボクセルグリッド比較で追加点・消失点のみ抽出 |
| **PCD 保存** | PCD v0.7 バイナリ形式 (x, y, z, intensity) |
| **録画時間** | 1 秒〜6 時間 (21,600 秒) を秒単位で設定 |
| **進捗表示** | 経過時間・残り時間・プログレスバーをリアルタイム更新 |
| **ログ** | 保存ファイル名をウィンドウ内にストリーミング表示 |

## 使い方

1. **接続設定** — 受信 IP アドレス（デフォルト `0.0.0.0` = 全 NIC）と UDP ポートを入力します。
2. **録画設定** — 録画時間（秒）と出力ディレクトリを設定します。セッションごとに `session_YYYYMMDD_HHMMSS/` サブフォルダが自動作成されます。
3. **詳細設定** ▸ *ボクセルサイズ* — デフォルト 0.05 m（5 cm）。小さくするほど細かな変化を検出します。
4. **▶ 録画開始** を押すと UDP 受信と差分保存が始まります。
5. **■ 停止** または設定した録画時間に達すると自動停止します。

## 出力ファイル

```
<出力ディレクトリ>/
└── session_20260101_120000/
    ├── frame_00000001_1234567890.pcd
    ├── frame_00000002_1234567950.pcd
    └── ...
```

- ファイル名: `frame_{フレームID:08d}_{タイムスタンプms}.pcd`
- 変化点が 0 のフレームはファイルを生成しません

### PCD フォーマット

```
# .PCD v0.7 - Point Cloud Data
VERSION 0.7
FIELDS x y z intensity
SIZE 4 4 4 4
TYPE F F F F
...
DATA binary
```

## Falcon K2 プロトコル仕様

本アプリは以下の Benewake 標準バイナリプロトコルを実装しています。

### UDP パケット構造

| オフセット | サイズ | 型 | 内容 |
|-----------|--------|-----|------|
| 0 | 2 | bytes | マジック: `0xAB, 0xCD` |
| 2 | 2 | uint16 | パケット種別 (`0x0101` = 点群) |
| 4 | 4 | uint32 | フレーム ID |
| 8 | 2 | uint16 | フレーム内パケットインデックス |
| 10 | 2 | uint16 | フレームあたり総パケット数 |
| 12 | 8 | uint64 | タイムスタンプ [μs] |
| 20 | 2 | uint16 | このパケットの点数 N |
| 22 | 2 | uint16 | 予約 |
| 24+ | N×14 | — | 点群データ |

### 点データ構造 (14 bytes/point)

| オフセット | サイズ | 型 | 内容 |
|-----------|--------|-----|------|
| 0 | 4 | float32 | X [m] |
| 4 | 4 | float32 | Y [m] |
| 8 | 4 | float32 | Z [m] |
| 12 | 1 | uint8 | Intensity (0–255) |
| 13 | 1 | uint8 | Tag / フラグ |

> **ファームウェアバージョンによる差異**
> 実機の挙動が合わない場合は `src/packet_parser.py` の
> `PACKET_MAGIC`, `PACKET_TYPE_PCLOUD`, `HEADER_STRUCT`, `POINT_STRUCT`
> 定数を調整してください。
